# Organizador de Gastos Pessoais

projeto que estou desenvolvendo para praticar Python e ter uma forma de organizar meus próprios gastos

a ideia é criar uma aplicação em que seja possível registrar compras, informar a categoria e o método de pagamento e acompanhar o total gasto. vou ir adicionando novas features conforme vou escrevendo o código e documentando, por enquanto há:

- Cadastrar compras.
- Separar gastos por categoria.
- Informar o método de pagamento.
- Listar compras cadastradas.
- Validar os dados informados.


pretendo adicionar também banco de dados e uma interface futuramente
